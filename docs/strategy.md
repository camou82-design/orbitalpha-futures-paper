# Strategy (skeleton)

## Goal

Paper trading 전용으로, **추세 필터 + 눌림 + 재돌파(entry) + 손절 중심(exit)** 구조를 최소 구현으로 시작한다.

## High-level flow

- **Trend filter**: 상위 타임프레임(예: 1h)에서 상승 추세만 통과(롱 전용)
- **Pullback**: 단기(예: 5m/15m)에서 눌림(조정) 구간 확인
- **Re-breakout**: 눌림 이후 전고점/기준선 재돌파 시 진입 신호 생성
- **Risk**: 진입과 동시에 손절가/익절가를 계산하고 포지션 크기를 제한

## Notes

- 초기 버전은 지표/로직을 단순화하고, 시그니처/데이터 플로우만 잡는다.
- 주문 전송/인증/실주문 API는 절대 포함하지 않는다.
